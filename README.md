# NovaTech Electronics Shop

Frontend demo bán đồ điện tử bằng React + Vite.

## Chạy project

```bash
npm install
npm run dev
```

Sau đó mở URL Vite hiển thị trong terminal.

## Tài khoản demo

### Customer
Bạn có thể đăng nhập bằng email bất kỳ, ví dụ:
`customer@gmail.com`
Mật khẩu: bất kỳ từ 6 ký tự.

### Admin
Đăng nhập với email có chứa từ "admin", ví dụ:
`admin@novatech.vn`
Mật khẩu: bất kỳ từ 6 ký tự. Sau khi đăng nhập sẽ tự động chuyển vào `/admin`.

## Tính năng

- Trang chủ hiện đại
- Danh sách sản phẩm
- Tìm kiếm và lọc theo danh mục
- Sắp xếp sản phẩm
- Chi tiết sản phẩm
- Yêu thích sản phẩm
- Giỏ hàng
- Thanh toán demo
- Đặt hàng
- Đăng nhập / đăng ký
- Hồ sơ cá nhân
- Danh sách đơn hàng
- Responsive
- Dữ liệu lưu bằng localStorage
- **Trang quản trị (Admin)**: tổng quan doanh thu/đơn hàng, quản lý sản phẩm (thêm/sửa/xóa), quản lý đơn hàng (đổi trạng thái, xem chi tiết), danh sách khách hàng

Không cần Backend để chạy demo.
